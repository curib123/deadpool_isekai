# This Isekai Has a Bug. Unfortunately, It's Me.

**Author:** minuszeroo  
**Repository:** `curib123/deadpool_isekai`  
**Genres:** Action • Adventure • Dark Fantasy • Comedy • Mystery • Isekai

This repository is the production workspace for the original Luck Everhart light-novel project.

Luck loves playing the mysterious figure who seems to know more than everyone else. His only supernatural power is passive luck, and he never identifies it as his power. Accidents make his performances look like elaborate plans. Witnesses supply explanations he could never have invented, and their belief creates work, enemies, and obligations he still has to survive.
