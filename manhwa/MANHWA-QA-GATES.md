# Manhwa QA Gates

## Gate M1 — Source Lock
PASS only when the exact canonical sources and episode boundary are recorded.

## Gate M2 — Adaptation
PASS only when every cut, compression, visual replacement, and dialogue reduction preserves canon and chapter purpose.

## Gate M3 — Storyboard
PASS only when pacing, geography, reveals, action readability, comedy timing, and vertical-scroll rhythm work before final rendering.

## Gate M4 — Asset Readiness
PASS only when all recurring characters, locations, creatures, props, costumes, and system visuals used by the episode have approved references or explicit provisional approval.

## Gate M5 — Panel Continuity
PASS only when adjacent panels preserve identity, spatial logic, state, and causality.

## Gate M6 — Visual Integrity
PASS only when anatomy, faces, hands, perspective, typography space, lighting, values, and effects meet production quality.

## Gate M7 — Canon
PASS only when the final episode matches manuscript events, knowledge states, systems, mystery locks, consequences, and character behavior.

## Gate M8 — Final
PASS only when lettering, SFX, crop safety, scroll spacing, file order, credits, and publication export are complete.

A failure at a gate returns the episode to the earliest stage that can correctly fix the issue.
