# Red Jackal — Turnaround Sheet Specification

**Status:** TEXTUAL TURNAROUND LOCK v1.0 — IMAGES PENDING  
**Purpose:** define exactly what the first approved model-turnaround set must preserve

# 1. Reference Set

Generate the following with neutral lens/perspective and consistent scale:

1. front full-body;
2. character-left profile;
3. character-right profile;
4. back full-body;
5. front-left 3/4;
6. front-right 3/4;
7. rear-left 3/4;
8. rear-right 3/4.

Use the same:
- face;
- hair;
- body proportions;
- neutral expression;
- costume state;
- lighting;
- reference background.

Do not mix costumes within one turnaround sheet.

# 2. Coordinate Rule

All left/right references in design files mean **the character's own left/right**, not the viewer's.

This rule is critical for:
- hair asymmetry;
- coat hem asymmetry;
- belt slope;
- crimson glove/seam detail;
- mask slash direction.

# 3. Head Invariants

Every view must preserve:
- face taper;
- jaw/chin;
- nose projection;
- ear position;
- eye size family;
- H1–H6 hair masses;
- upper-nape hair length.

The character-right forward hair lock remains identifiable across front/3/4 views.

# 4. Body Invariants

Every view must preserve:
- ~7.5-head construction;
- shoulder width;
- waist ratio;
- hip width;
- arm length;
- hand size;
- leg length;
- neck length.

No perspective-enhanced shoulders or legs on a calibration sheet.

# 5. RJ-COSTUME-ARRIVAL-001 Turnaround

Must show:
- fitted charcoal-black upper;
- low-profile short standing collar;
- subtle diagonal upper construction seam;
- flexible tapered dark trousers;
- dark ankle boots;
- no signature coat;
- no mask;
- no signature layered-belt arrangement;
- no large crimson accent.

This sheet becomes the CH001 costume anchor once approved.

# 6. RJ-COSTUME-SIGNATURE-001 Turnaround

Must show:
- charcoal long coat;
- character-left hem slightly longer;
- rear split;
- medium structured-soft collar;
- restrained crimson under-collar / inner facing;
- two-belt layout;
- secondary belt sloping character-right waist → character-left hip;
- fitted wrist-length gloves;
- dark tapered trousers;
- above-ankle/below-mid-calf boots.

The coat must not hide all body landmarks; reference sheet may include one coat-open inset.

# 7. Back View Requirements

Back view must establish:
- hair upper-nape edge;
- coat center/back seams;
- rear split;
- belt continuation;
- boot rear construction.

Do not invent a giant back emblem.

# 8. Side View Requirements

Profiles must establish:
- forehead/nose/lip/chin projection;
- chest/abdomen posture;
- coat thickness;
- boot sole thickness;
- mask depth when mask sheet is later produced.

# 9. Turnaround Approval Checklist

PASS only if:
- all views clearly depict one person;
- costume geometry matches between views;
- face age remains stable;
- hair silhouette does not change;
- asymmetry does not flip sides;
- crimson placement is identical;
- no new accessories appear;
- no visual element contradicts canon.

- `RJ-REF-002` — turnaround candidate.
