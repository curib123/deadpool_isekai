# System UI Visuals

## Rule

The World System's visual presentation must be derived from systems canon and actual manuscript appearances. Do not default to a generic game HUD.

Before locking any UI establish:

- who can perceive it;
- what information it is allowed to show;
- whether it is physical, perceptual, magical, or representational;
- typography;
- framing;
- color/value;
- animation implied by panel sequence.

Red Jackal's UNDEFINED/recognition failures must not be visualized in a way that reveals protected mystery truth early.
