# Greywake Interiors

Interiors must reflect frontier life, function, local economy, and available materials.

Create approved interior kits only when canon requires them. Record:

- room function;
- structure/materials;
- light sources;
- storage;
- furniture;
- tools;
- signage;
- traffic path;
- recurring props;
- damage/current state.

Avoid generic luxury-fantasy interiors unless canon specifically establishes them.
