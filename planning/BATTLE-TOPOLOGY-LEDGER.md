# Battle Topology Ledger

**Status:** CURRENT — 2026-10-03

# 1. Purpose
Prevent repeated fights and prevent Fortune Distortion from becoming an automatic win button.

# 2. Matchup Card
For every major action sequence record:
- Luck's objective;
- enemy objective;
- terrain;
- civilians/allies;
- tools/equipment;
- enemy advantage;
- Luck's ordinary disadvantage;
- existing variables available for probability shift;
- decisive opening;
- who converts the opening;
- cost;
- misunderstanding/reputation effect.

# 3. Topology Types
Rotate among:
- pursuit;
- hold/choke point;
- escort;
- rescue;
- terrain collapse;
- multi-point defense;
- human confrontation;
- evidence protection;
- infrastructure emergency;
- retreat/escape;
- monster displacement;
- crowd/traffic hazard.

Do not repeat the same “enemy attacks → slips → Luck wins” topology.

# 4. Greywake Reference
Greywake action should progress from:
- messy personal survival;
- work hazards;
- pack pressure;
- route investigation;
- backflow rescue;
- migration corridor defense;
- combined environmental/human climax.

# 5. Merrowgate Reference
Merrowgate action should progress from:
- cargo-transfer hazards;
- dock rescue;
- evidence pursuit;
- machinery failure;
- multi-route harbor crisis.

No conjured rescue structures.

# 6. Fortune Distortion Rule
Major probability turns use pre-established variables and leave human work afterward.

# 7. Cast Rule
Specialists retain specialist ownership.

# 8. Consequence Rule
Every major battle/action scene creates at least one carried consequence: wound, damage, evidence change, resource loss, political effect, rumor, or relationship shift.

# 9. Current Verdict
Future action planning is valid only under the Luck Everhart / Fortune Distortion structure.
