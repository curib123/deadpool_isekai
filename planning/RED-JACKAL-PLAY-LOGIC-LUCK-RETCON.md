# Red Jackal Power Identity Retcon — Play Logic / Luck / Fourth Wall

**Project:** This Isekai Has a Bug. Unfortunately, It's Me.  
**Status:** LOCKED AUTHORIAL RETCON  
**Effective:** 2026-09-26  
**Priority:** Overrides all conflicting power descriptions in older files.

# 1. Final Power Set

Red Jackal has three signature anomaly expressions:

1. **Play Logic**
2. **Jackal Luck**
3. **Fourth-Wall Pause**

There is **no separate regeneration power**.

Any healing, reconstitution, impossible survival, body correction, or recovery previously described as Regeneration / Self-Restoration is now a **Play Logic expression applied automatically to Red's own body**.

# 2. Play Logic

Play Logic is Red's primary power.

It allows imagination, intent, performance, self-concept, comedy logic, and scene logic to negotiate with reality.

Possible expressions include:
- impossible props;
- temporary objects;
- absurd weapons;
- cartoon physics;
- spatial jokes;
- transformations;
- symbolic effects;
- environmental edits;
- conceptual interactions;
- body restoration;
- surviving injuries that should be lethal;
- impossible physical continuity.

There is no known intrinsic raw-power ceiling.

Red does not need to consciously understand every expression.

Some Play Logic is deliberate.

Some is reflexive.

Some is automatic because Red's self-concept simply refuses the current physical state.

## 2.1 Body Restoration Is Play Logic

When Red is wounded, his body may:
- close wounds;
- restore damaged tissue;
- reconnect or rebuild;
- reject lethal finality;
- return toward the body Red unconsciously accepts as "himself."

This is **not**:
- a healing spell;
- a regeneration skill;
- a second power;
- an HP recovery mechanic;
- a limited resource.

It is reality being forced back toward Red's persistent self-concept through Play Logic.

Pain can still happen.

Blood can still happen.

Temporary injury can still affect a scene.

Damage to other people, property, trust, evidence, timing and politics does not rewind.

# 3. Jackal Luck

Jackal Luck is Red's passive probability-distortion power.

Red does not command it like a spell.

It bends coincidence, timing, chance and circumstance around him.

Examples:
- the one loose board breaks at exactly the useful moment;
- the wrong person overhears the right sentence;
- a thrown object lands somewhere absurdly useful;
- Red chooses a random direction and walks into the relevant problem;
- an enemy's perfect plan fails because of a tiny ordinary coincidence;
- a missing object turns up somewhere ridiculous;
- a socially perfect interruption arrives;
- witnesses misread an accident as deliberate foresight;
- Red survives or benefits from odds that should have been terrible.

Jackal Luck should feel like:
**the universe accidentally helping Red commit to the bit.**

## 3.1 Luck Is Not Absolute Fate Control

Jackal Luck does **not** mean:
- Red always wins;
- Red can choose exact probabilities;
- every gamble succeeds;
- other people are automatically protected;
- consequences disappear;
- Fate becomes his servant;
- he can consciously order reality to produce a specific coincidence.

Luck may:
- help him;
- make a scene funnier;
- create a useful accident;
- create a worse but more interesting problem;
- save Red while leaving everyone else with the consequences.

Sometimes Red's luck should make his life more complicated.

## 3.2 Luck + Accidental Legend

Jackal Luck is the mechanical foundation for part of Red's accidental-mastermind reputation.

Typical chain:

**Red guesses / improvises / acts selfishly → Jackal Luck creates a suspiciously perfect coincidence → witnesses assume planning → Red's legend grows**

Red may:
- have no idea why it worked;
- pretend he planned it;
- accept credit;
- privately wonder whether reality is showing off.

# 4. Fourth-Wall Pause

Fourth-Wall Pause remains unchanged.

A genuine direct address to the external reader/audience:
- freezes local Veyran time;
- freezes local motion and sound;
- allows Red to speak directly to the reader;
- resumes at the same causal instant.

The audience is not his power source.

# 5. Relationship Between the Three Powers

## Play Logic
**Red makes the impossible real.**

## Jackal Luck
**The possible becomes suspiciously convenient.**

## Fourth-Wall Pause
**Red temporarily steps outside Veyr's active moment to address the audience.**

These powers share the Soul-Drift anomaly root but remain distinguishable in presentation.

# 6. Combat Rule

Raw combat tension is never:
**Can Red unlock enough power?**

It comes from:
- what Red chooses to do;
- what he knows;
- simultaneous objectives;
- civilians;
- evidence;
- ecology;
- politics;
- other characters' vulnerability;
- consequences already in motion;
- Jackal Luck helping in a way Red did not expect;
- Play Logic solving one problem while creating another.

# 7. Narration Presentation

The current prose standard is **distant third-person limited**.

Power should be shown naturally through:
- visible action;
- lively dialogue;
- other characters reacting;
- brief selective Red thoughts.

Avoid author-facing explanations such as:
- "this is not regeneration";
- "there is no stamina meter";
- "this is luck power";
- "Play Logic activated."

The reader should understand the system through repeated behavior and later explanation.

# 8. Supersession

Older references to:
- Regeneration;
- Self-Restoration;
- regeneration as a separate ability;
- two independent Play Logic / regeneration roots;
- luck as only a non-mechanical narrative effect

are superseded.

The current power identity is:

**PLAY LOGIC + JACKAL LUCK + FOURTH-WALL PAUSE**
