# Story Planning

**Current authority:** `planning/LUCK-EVERHART-STRUCTURAL-STORY-BIBLE.md`  
**Status:** CURRENT — 2026-10-03

# 1. Planning Principle

Plan from causality, not spectacle.

For every chapter:

**goal → obstacle → attempt → turn → change → carryover**

For every lucky event:

**staged ordinary variable → improbable alignment → opening → somebody acts → outcome → consequence**

For every misunderstanding:

**visible evidence → mistaken motive theory → changed decision/expectation → later consequence**

# 2. Chapter Sheet

Each chapter plan must contain:

- Chapter ID / title
- Volume / destination
- POV
- opening situation
- immediate objective
- concrete obstacle
- Luck-specific choice or performance
- supporting-character objective
- attempt/escalation
- Fortune Distortion causal chain, if any
- misunderstanding type, if any
- what changes
- consequence carried forward
- mystery/foreshadowing boundary
- continuity dependencies
- ending beat

Do not include:
- Play Logic;
- manifestations/constructs;
- regeneration;
- power stages;
- deliberate luck activation;
- raw-power reveal counts.

# 3. Scene Sheet

Each scene must contain:

- scene purpose
- location/staging
- participants
- goal
- obstacle
- attempt
- turn
- change
- carryover

If the scene ends in the same practical state and adds no necessary evidence/relationship change, combine or remove it.

# 4. Engagement Rule

Every chapter needs a meaningful engagement beat, which may be:

- danger;
- work under pressure;
- investigation;
- confrontation;
- negotiation;
- pursuit;
- rescue;
- political collision;
- plan failure;
- discovery;
- irreversible choice;
- consequence under pressure.

A battle is optional.

# 5. Luck Event Rule

Luck events are not mandatory every chapter.

When used, the reader must be able to reconstruct the physical/social chain. Supporting characters must still do real work.

No chapter may end with “Luck wins because luck” without visible mechanics.

# 6. Misunderstanding Rotation

Across adjacent chapters, avoid repeating the same misunderstanding result.

Possible results:
- payment;
- suspicion;
- fear;
- obligation;
- legal scrutiny;
- political attention;
- enemy retreat;
- unwanted trust;
- failed performance;
- rumor mutation;
- somebody else receiving credit/blame.

# 7. Consequence Tracking

Before drafting a chapter, review:
- current injuries;
- money/resources;
- location/travel time;
- promises/debts;
- damaged infrastructure;
- evidence;
- legal status;
- reputation;
- relationships;
- active mysteries.

# 8. Current Audit Mode

CH001–CH027 are being re-audited under the current structural story bible.

Audit labels:
- KEEP
- TARGETED FIX
- SCENE REWRITE
- CHAPTER REWRITE

Strong prose is preserved. Revision is required only where structure, causality, continuity, POV, power rules, or character consistency fail.

# 9. Production Gates

For new material:

1. destination/arc architecture;
2. chapter roadmap;
3. scene architecture;
4. manuscript;
5. structural/continuity QA;
6. reader-facing copy.

No historical Gate PASS overrides a later author-directed retcon.

# Final Rule

**Fix the owning structural document before hiding a structural conflict inside prose.**
