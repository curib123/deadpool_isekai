# Scene QA Standard

**Status:** CURRENT — 2026-10-03  
**Authority:** `series/STORY-STRUCTURE-BIBLE.md`

A scene passes only if all relevant checks pass.

# 1. Purpose
- Luck has an immediate goal.
- At least one other participant has an independent goal.
- The scene changes options, knowledge, danger, resources, relationship, or obligation.

# 2. Staging
- important people are located clearly;
- exits/hazards/tools are introduced before they matter;
- movement can be pictured without retroactive geography;
- no convenient object appears only at the instant it saves Luck.

# 3. Cause and Effect
- attempts produce consequences;
- major luck chains use pre-existing variables;
- Fortune Distortion never creates an impossible result;
- somebody must convert the opening into action.

# 4. Character
- Luck remains theatrical, dry, opportunistic, and human;
- serious mode does not erase personality;
- supporting characters retain competence;
- nobody exists only to admire Luck.

# 5. Misunderstanding
If present:
- witness evidence is real;
- witness motive interpretation may be wrong;
- the misunderstanding changes a later decision/relationship/threat/obligation.

# 6. Continuity
- injuries persist;
- resources persist;
- evidence persists;
- legal/reputation consequences persist;
- character knowledge does not jump ahead.

# 7. Dialogue
- each speaker wants something;
- lines persuade, test, bargain, conceal, refuse, threaten, or investigate;
- exposition-only exchanges are cut or embedded in conflict.

# 8. POV
Distant third-person limited centered on Luck Everhart.
No head-hopping.
No first-person default narration.

# 9. Removed Powers
Automatic fail if current prose uses:
- Play Logic;
- supernatural regeneration;
- time stop;
- conjured tools/structures;
- Stage progression;
- conscious probability control.

# Verdict
**PASS** only when the scene has clear staging, causal movement, character ownership, and a meaningful exit condition.
