# Production Flow

## Phase 1 — Foundation
Validate world, systems, characters, mysteries.

## Phase 2 — Destination
Select an existing destination with a distinct local identity.

## Phase 3 — Volume
Define:
- local question;
- antagonist;
- independent supporting cast;
- Luck's practical reason to engage;
- Luck-caused/enabled mistake;
- midpoint;
- reversal;
- climax;
- resolution;
- departure.

## Phase 4 — Chapter Roadmap
Each chapter requires:
- immediate objective;
- conflict;
- change;
- continuity;
- ending pull.

## Phase 5 — Scene Architecture
Each scene requires:
- goal;
- other-character goal;
- staging;
- obstacle;
- attempt;
- turn;
- consequence;
- exit condition.

## Phase 6 — Manuscript
Write under current prose/power/POV rules.

## Phase 7 — QA
Run:
- scene QA;
- battle QA if relevant;
- continuity;
- mystery boundary;
- prose/style.

## Phase 8 — Canonization
Update knowledge and consequence records.

## Phase 9 — Publication Copy
Strip production metadata only; do not silently change canon.

# No-Skip Rule
Do not draft a new chapter from a legacy roadmap when the current architecture/roadmap has not been checked.

# Escalation
When conflict is found:
- identify owner;
- repair owner first;
- rerun downstream QA.
